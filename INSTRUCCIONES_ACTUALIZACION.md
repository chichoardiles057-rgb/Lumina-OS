# Actualización Lumina OS v0.2.0

Esta carpeta es una **actualización** para el proyecto `Lumina OS` que ya abriste en Visual Studio Code.

1. Descargá y descomprimí el ZIP.
2. Abrí la carpeta resultante `Lumina_OS_v0.2.0_update`.
3. Seleccioná todo su contenido y copialo dentro de tu carpeta existente `Lumina OS`.
4. Cuando macOS pregunte, elegí **Reemplazar** para actualizar los archivos `README.md`, `CHANGELOG.md`, `VERSION` y `docs/roadmap/ROADMAP.md`.
5. Volvé a Visual Studio Code: los archivos nuevos aparecerán automáticamente.
6. Todavía **no ejecutes** el archivo SQL ni subas datos de Mercado Libre a GitHub.

Después de revisar los documentos, registrá la actualización con Git:

```bash
git add .
git commit -m "v0.2.0 - Modelo de datos inicial"
git push
```
